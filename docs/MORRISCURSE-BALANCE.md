Таблица ниже сгенерирована из бестиария (HP/урон/броня/XP — итоговые статы сервера).

## Кривые
- Опыт до следующего уровня: `xpNeed(L) = round(20 + 315·L^2.1)`; опыт за моба: `mobXp(L) = round(5 + 2.4·L^1.42)`, множитель за разницу уровней `xpLevelMult`.
- Ярусы: `tier = ceil(L/5)` (1–5) → регионы Аринара: рощи/луга (1–5), пустоши/сады (6–10), копи/кряж (11–15), пилоны/глитч (16–20), кратер/тонкие земли (21–25). Внешнее кольцо Поляны — ур. 1–3.
- Бюджет предмета: `(2 + 0.62·L) × RARITY_BUDGET` (common 1 … mythic 2.1); оружие: `(4.5 + 0.85·L) × RARITY_DMG`.
- Требуемый уровень предмета = ур. предмета − 1.
- Мобы: целевое время убийства `ttk = 3.5 + 2.5·(L−1)/24` с у эталонного героя; броня `round(0.9·L)`; множители роли (melee/swarm/charger/ranged/caster/tank) и размера (s/l/boss/huge).
- Дроп (за кусок сета, %): обычный моб common 4 / uncommon 2.5 / rare 0.7 / epic 0.2 / legendary 0.12 / mythic 0.1; редкий 20/12/5/1.2/0.4/0.1; босс 40/25/10/3/0.8/0.1; множитель куска сета 0.5.
- Все броски — сервер, `crypto.getRandomValues`; таблицы кода совпадают с D1 `mob_drops` (проверка хэша библиотеки при старте).
