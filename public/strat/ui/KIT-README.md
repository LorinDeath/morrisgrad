# Партия Чёрных королей — UI kit v1 (стиль C)

Ар-деко: толстая чистая чернильная линия, плоские заливки, палитра чёрный / золото / слоновая кость / красный.
Весь набор нарисован кодом (вектор на PIL/numpy, суперсэмплинг 4×). Нейрогенерация не использовалась.
Каждый PNG имеет SVG-близнеца, построенного из тех же полигонов.

ТЗ `minigame-tz/art-request-ui.md` на момент сборки не существовало. Имена файлов, размеры и нарезка придуманы здесь.
Если ТЗ появится, переименование делается в `src/*.py` (функция `save`) и в `check_ui.py`.

## Структура

```
ui-v1/
  frames/ buttons/ icons/ crests/ banners/ screens/ cards/ ornaments/   прозрачные PNG (RGBA)
  svg/<категория>/<имя>.svg       SVG из тех же полигонов (текст переведён в контуры)
  manifest.json                   имя → категория, пути png/svg, размер, нарезка, заметка
  previews/ui_kit_collage.png     все ассеты с подписями и пример растяжки 9-slice
  previews/ui_mockup.png          макет игрового экрана 1920×1080
  check_ui.py                     автопроверка (печатает RESULT: OK)
  src/                            исходники
```

## Нарезка (9-slice / 3-slice)

Нарезка записывается как L/T/R/B, в пикселях от края. Растягивать можно только середину.
- **9-slice:** углы рисуются 1:1, края тянутся по одной оси, центр заливается.
- **3-slice (горизонтальная):** левый и правый концы рисуются 1:1, середина тянется по ширине, высота фиксирована.

Полосы растяжки в PNG однородны до пикселя: `check_ui.py` проверяет это точным сравнением.
Значит, растягивать можно хоть nearest, хоть linear.

| Ассет | Размер | Нарезка | Минимальный размер |
|---|---|---|---|
| panel_frame, panel_ivory | 192×192 | 9-slice 48/48/48/48 | 96×96 |
| modal_frame | 256×256 | 9-slice 88/88/88/88 | 176×176 |
| title_plate | 384×96 | 3-slice L96 R96 | ширина 192 |
| btn_primary_*, btn_secondary_* | 240×72 | 3-slice L40 R40 | ширина 80 |
| btn_endturn_* (пустая) | 360×120 | 3-slice L100 R100 | ширина 200 |
| divider_h | 512×32 | 3-slice L96 R96 | ширина 192 |

Рамки можно уменьшать целиком: например, в макете panel_frame использован в масштабе 0.75 с отступами 36.
Кнопки с надписью (`btn_endturn_text_*`) имеют фиксированный размер.
Для другой надписи берите пустую `btn_endturn_*` и пишите текст поверх: Oswald Bold 34, золото `#f3d27a`, обводка `#1a1420`.

## Состояния

- **Кнопки:** `normal`, `hover` (светлее), `pressed` (корпус сдвинут на 4 px вниз, тень спрятана), `disabled` (серые).
- **Карты и рамки технологий:** `locked` (серые, затемнены, замок), `available` (золото, внешний светлый контур), `learned` (золото, красное поле, печать с галочкой справа сверху).

## Иконки

Набор ресурсов: `gold`, `knowledge`, `glory` (Слава), `ap` (ОД), `growth` (рост), `armor` (броня), `attack` (атака), `hp` (здоровье).
- Версия `_64`: линия 2.5 px.
- Версия `_32`: отдельный упрощённый рисунок с линией 1.75 px, а не уменьшенная копия. `check_ui.py` это проверяет.

## Шрифты (установлены на машине, кириллица есть)

- **Oswald Bold 700** (`/usr/share/fonts/truetype/sand-box/google/Oswald/Oswald-VariableFont_wght.ttf`): кнопки, баннер, цифры, весь живой UI-текст. Для мелкого текста используйте вес 500.
- **Playfair Display Black 900** (`/usr/share/fonts/truetype/sand-box/google/Playfair Display/PlayfairDisplay-VariableFont_wght.ttf`): заголовки «ПОБЕДА» и «ПОРАЖЕНИЕ».

Лицензия обоих шрифтов — OFL. В ассетах текст переведён в кривые, так что шрифт нужен только для живого текста в игре.

## Пересборка

```
cd ui-v1/src
timeout 600 nice -n 19 python3 build_all.py   # все PNG + SVG + manifest.json (~1 мин)
timeout 600 nice -n 19 python3 collage.py     # previews/ui_kit_collage.png
timeout 600 nice -n 19 python3 mockup.py      # previews/ui_mockup.png (читает terrain-v1 и race-*-v1)
cd .. && python3 check_ui.py                  # RESULT: OK
```

Модули в `src/`:
- `vk.py`: движок; сцена из полигонов → PNG с SS 4× и SVG.
- `vtext.py`: текст в контуры через fontTools.
- `common.py`: палитра, мотивы, `save`, `enforce_slice`.
- По модулю на категорию: `frames`, `buttons`, `icons`, `crests`, `banners`, `screens`, `cards`, `ornaments`.

## Что проверяет check_ui.py

- Полнота набора: все 60 ассетов, у каждого есть и PNG, и SVG.
- Размеры.
- Режим RGBA, прозрачные углы, непустое изображение.
- Однородность полос растяжки 9/3-slice и тест растяжки.
- SVG: валидный XML, width/height/viewBox совпадают с PNG, корректные path data и цвета.
- 32-px иконки не являются даунскейлом 64-px.
- Наличие превью и README.

## Известные недостатки

- SVG не получают пост-обработку `enforce_slice`: полосы растяжки там однородны по геометрии, но сглаживание может отличаться на долю пикселя. Для 9-slice в движке берите PNG.
- Трещина на короне в `screen_defeat` читается слабо, нужен крупный план.
- Чернильная обводка на тёмных панелях почти не видна (так задумано: чернила темнее панели). Силуэт держит золото.
- В макете полоса HP, полоса Славы, подсветка клеток и счётчики нарисованы прямо в mockup.py и в кит не входят.
  В движке их проще делать примитивами в цветах палитры.
