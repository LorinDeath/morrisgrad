# Эффекты Альказака (для Художника)

Настройки и точки — `src/assets/mc/city/city_fx.json`; живые ручки — админка «🏰 Город» → «Дым и очаги» (`fx.*`).

## Дым из труб — `fx/chimney_smoke.png` (необязательно)
- PNG RGBA **256 × 32**: 8 кадров **32 × 32** в строку, клуб по центру кадра, светлый нейтральный (цвет домножается на `smoke.color`).
- Кадр = возраст частицы: 0 — только вышел из трубы … 7 — почти растаял. Прозрачность и рост делает игра.
- Пока файла нет — процедурный мягкий клуб.
- Точки труб: `chimneys.<ключ картинки здания> = [[x, верх трубы y], …]` в px картинки здания. Запечённый в здании дым
  над трубой стирается (`clip`), поэтому в новых bld_*.png дым можно не рисовать.

## Очаг в домах
- Огонь — пропс `dm_hearth` (props_dark_p32, строка 26, 6 кадров 32×48 @10 к/с) + `_glow` в props_dark_p32_glow.
- Свет (ореол и пятно на полу) — код, мерцание: `fx.hearthFlick` (сила), `fx.hearthSpeed`, `fx.hearthK` (яркость), `fx.hearthR` (размер).
