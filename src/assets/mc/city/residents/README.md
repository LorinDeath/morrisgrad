(поле `npc.N.sprite`, только `a-z 0-9 _`). Пока файла нет, житель рисуется строкой «вида» (`look`: alzi / leyr / petr) из heroes_atlas.

## Формат
- PNG RGBA, **1152 × 60** px: одна строка из 24 кадров **48 × 60** (как строка NPC в heroes_atlas).
- Кадры: 4 направления × 6 — `0–5` вниз, `6–11` влево, `12–17` вправо, `18–23` вверх.
- В каждом направлении: `0` шаг A, `1` стойка, `2` шаг B, `3` вдох (дыхание стоя), `4–5` запас — игра их **не показывает** (у Знахаря там заточка кинжала — решение Алекса: такого покоя нет; стоя — только стойка/вдох).
- Ступни — у нижнего края кадра (линия земли y ≈ 58), персонаж по центру по X; без тени (тень рисует игра).
- Пиксель-арт без сглаживания, палитра тёмного Альказака.

Положили файл → пересборка клиента, код не трогать. Имена и точки — в админке (данные, без кода).

## Свечение и контур
- `<ключ>_glow.png` (тот же размер 1152 × 60, те же кадры) — только светящиеся пиксели (глаза, камень); остальное прозрачно. Рисуется аддитивно, без ночной подкраски, ночью — поверх маски (светит сам). Сила — админка «🏰 Город» → `fx.resGlowK`, выкл — `fx.resGlow`.
- `fx.resRim` (0–1, по умолчанию 0.6) — контур 1 px вокруг жителя: тёмные волосы/одежда не сливаются с тёмной землёй. 0 — выкл.
