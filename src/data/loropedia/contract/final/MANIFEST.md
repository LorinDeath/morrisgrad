# Адаптация к контракту Loropedia v1.0.0

Контракт: `/workspace/loropedia-contract-v1/src/data/loropedia/contract/` (schema, fields, fixtures/example-corpus, coverage). Перед адаптацией все четыре файла прочитаны.
Исходники `export/` и `review/` не изменены. Репозиторий и сайт не затрагивались.

## Файлы
- `corpus.json`: корпус по контракту.
- `gaps.json`: что не удалось выразить схемой; эти элементы исключены.
- `coverage.json`: покрытие и список рабочих seed.
- `build_contract.py`: сборка корпуса.
- `validate_contract.py`: проверка через jsonschema 4.26, Draft 2020-12, плюс проверки ниже.

## Проверки (результат: OK)
- Корпус проходит JSON Schema; фикстура из контракта тоже валидна.
- Ни одного дубля id.
- У каждого фрагмента sha256 файла совпадает с locator, цитата дословно стоит в указанном абзаце, spoilerFrom равен главе фрагмента.
- У всех записей существуют sourceIds.
- Ни одна запись не открывается раньше своего источника. Источники одной записи не смешивают книги.
- truthClaim=false везде.
- Нет запрещённых формулировок: гибель Кьют, временная петля, переселение Лорин, «Идея Алекса».

## Правила адаптации
- Книги: `book:obitel`, `book:pravednye`, `book:kill`. Прогресс у каждой свой. chapterNumber начинается с 1 (Пролог = 1, Гл.4 = 12, И2.9 = 22). Частей нет, поэтому partId и partNumber равны null.
- Каждый фрагмент — одна точная цитата. В locator: fb2 с sha256, название главы, номер главы, файл с sha256, номер абзаца.
- provenance.mode:
  - `memory` — воспоминания Мариэль (girl.12–14);
  - `retelling` — слова Велеса о Нофорде и пересказ Кавеги (veles.msg.01, .02, .04);
  - `direct` — остальное.
- Применены выводы semantic review:
  - 7 формулировок заменены на suggestedText. У каждой проверены источник и порог;
  - blade.03 поднят до главы 12 (Гл.4), добавлен фрагмент ch_12:7 с именем «Кэйдж»;
  - в stasis.02–04 указано, что это восприятие Кавеги;
  - в veles.msg.01 сказано, что это слова Велеса, на месте он не был, суд не состоялся.
- Сущности разведены по книгам: `ent:pravednye.likyor`, `ent:kill.likyor`, `ent:pravednye.kinzhal`, `ent:kill.klinok` отдельно от `ent:obitel.*`. Алиасов нет, имена с пометкой книги. Связей между книгами нет, Листаф не используется.
- knownBy перенесён как relation `knows` с меткой «присутствовал / услышал». Это не означает, что персонаж знает наверняка. Перенесены только проверенные связи для seed Кавега–Нофорд.
- Гипотезы (6 из 7):
  - spoilerFrom = максимальный порог из всех доводов «за» и «против»; пробелы (gap) получают тот же порог;
  - status `disputed`, label «Предположения Историка — не канон»;
  - `hyp.sister.identity` исключена: её доводы взяты из двух книг, а spoilerFrom выражает только одну книгу;
  - в `hyp.blade.origin` упоминание другой книги заменено нейтральным пробелом.
- Seed оформлены как derived с optional=true. По контракту такая запись закрыта, пока закрыт любой её источник.

## Исключено (gaps.json)
- pk.08 и kill.05: это тексты аннотаций, у них нет chapterId.
- hyp.sister.identity: доводы из двух книг.
- 9 открытых вопросов: в контракте нет типа записи без источника.
- knownBy остальных фактов.
- reader как сущность.
- Поле notes.
- entityIds у фактов.
- Части книг (parts).
